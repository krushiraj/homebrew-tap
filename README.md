# krushiraj/homebrew-tap

Homebrew tap. Casks are generated by [GoReleaser](https://goreleaser.com) on
release — do not edit them by hand. Formulae are updated with `bump.sh`.

## edf-tool

Monthly export-of-services invoice + HDFC Bank EDF form generator. Fully offline.

```sh
brew install krushiraj/tap/edf-tool
```

Source: [krushiraj/edf-tool](https://github.com/krushiraj/edf-tool)

New edf-tool releases are picked up automatically by the `bump-edf-tool` workflow
(every 6 hours; it installs and tests the formula before pushing). To run it now:

```sh
gh workflow run bump-edf-tool -R krushiraj/homebrew-tap
```

Or by hand: `./bump.sh 0.1.1 && git commit -am "edf-tool 0.1.1" && git push`

## babygo

[Go by Example](https://gobyexample.com), run like
[rustlings](https://github.com/rust-lang/rustlings).

```sh
brew install krushiraj/tap/babygo
babygo init && cd babygo && babygo
```

Source: [krushiraj/babygo](https://github.com/krushiraj/babygo)
